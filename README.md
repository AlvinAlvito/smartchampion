# Pelatihan POSI

Web ekosistem pelatihan POSI: landing page produk, katalog & pendaftaran **Champion Online Class (COC)** dengan pembayaran Midtrans, dashboard peserta (jadwal & materi), **games edukasi** dengan leaderboard, serta panel admin (statistik, performa admin, Data Master Lead, Data Blast, Peserta Terdaftar (semua produk kelas), produk & materi, games, pengguna).

Stack: Next.js 16 (App Router, Server Actions) · MySQL 8 · Prisma 6 · Tailwind CSS 4 · Recharts.

## Menjalankan di lokal

1. Nyalakan MySQL (Laragon). Sesuaikan `DATABASE_URL` di `.env` (salin dari `.env.example`).
2. Pasang dependensi dan siapkan database:
   ```bash
   npm install
   npx prisma migrate deploy   # buat tabel
   npm run db:seed             # isi data (MENGHAPUS data lama)
   npm run dev
   ```
3. Buka http://localhost:3000

## Pembayaran Midtrans

Isi `MIDTRANS_SERVER_KEY` dan `NEXT_PUBLIC_MIDTRANS_CLIENT_KEY` (sandbox) di `.env`.
- Jika kunci **kosong**, halaman pembayaran berjalan dalam **mode simulasi**: ada tombol "Simulasikan Pembayaran Berhasil" (hanya aktif di non-production).
- Notification URL di dashboard Midtrans: `https://<domain>/api/midtrans/notification` (tanda tangan diverifikasi).
- Di localhost webhook tidak bisa dijangkau Midtrans, jadi status juga disinkronkan otomatis saat peserta membuka halaman pembayaran atau menekan "Cek status pembayaran".

## Alur data penting
- **Chat WA: emoji, gambar, auto-balas AI**
  - Tombol emoji di kolom balasan (`src/components/emoji-picker.tsx`, tanpa library).
  - Gambar masuk (JPG/PNG/WebP ≤ 5 MB) disimpan wa-gateway di `wa-gateway/media/<sesi>/` (izin 600, dihapus otomatis setelah 90 hari) dan ditampilkan lewat `/api/admin/wa/media?id=` (akses sama dengan membaca chat). Butuh redeploy & restart wa-gateway.
  - **Auto-balas AI** (saklar per nomor di bilah Chat WA; `src/lib/wa-autoreply.ts`, `askWaChatbot` di `src/lib/chatbot.ts`): memakai basis pengetahuan & data sistem yang sama dengan chatbot situs. Hanya pesan baru (≤ 5 menit), menunggu 6 detik agar pesan beruntun dijawab sekali, maks. 12 balasan AI/chat/jam, setiap balasan diberi keterangan "dijawab otomatis oleh AI". Cek fakta: AI wajib mengutip DATA persis dan setiap angka di jawaban harus ada di kutipan — gagal → tidak dikirim. Tidak tahu / gagal cek fakta → "Tunggu sebentar yaah… admin akan menjawab"; customer kesal → permintaan maaf; pesan gambar/suara/dokumen → "admin akan mengecek". Setelah itu AI **dijeda di chat tersebut** (label *Admin* di daftar chat) sampai admin klik *Aktifkan AI lagi*. Admin membalas dari panel/HP → AI juga dijeda di chat itu.
- **Generate jobdesk AI** (halaman Jobdesk: tombol *Generate AI* di jobdesk harian & *Generate agenda AI* di agenda pekanan; `src/lib/jobdesk-ai.ts`): beban kerja admin dihitung pasti dari database — Master Lead (lewat jadwal follow-up, follow-up hari ini, menunggu bayar, lunas belum masuk kelas, lead baru belum dikontak, Paid pekan ini/lalu), Data Blast (target **1.000 kontak/pekan**, sisa & target per hari kerja), Chat WA (chat menunggu balasan, > 24 jam, belum dibaca). Angka itu jadi kerangka; AI (Groq) merapikan judul, cara kerja, nama yang didahulukan, jam, prioritas, dan tautan ke agenda pekanan tanpa mengubah angka. Hasil tampil sebagai pratinjau → admin memilih → disimpan (tidak menduplikasi judul yang sudah ada; fokus pekan hanya diisi bila kosong; centang uji 3LD tetap oleh admin). AI gagal/lebih dari 40 detik → penyusun berbasis aturan. Admin untuk dirinya sendiri, Root untuk admin yang dipilih, Superadmin tidak.
- **Nilai manual & Try Out Mimpi.mu** (halaman Rekap kelas): klik nilai P1…Pn untuk mengisi/mengubah nilai pertemuan (0–100, catatan opsional) — disimpan di `meeting_scores` dan **menggantikan** nilai worksheet (tampil ungu ✎; *Pakai nilai worksheet* untuk kembali). Kolom **Try Out** = nilai Try Out Mimpi.mu setelah pelatihan (`class_results.tryoutScore`). Nilai akhir = rata-rata semua nilai pertemuan + Try Out (`src/lib/class-recap.ts`) → grade, rapor & sertifikat. Superadmin hanya melihat.
- **Rapor & sertifikat format POSI**: rapor PDF mengikuti contoh *Champion's Online Class – RAPORT* (latar `assets/report/latar-rapor.jpg`; Nama, Kelas, Work Sheet 1…n + Try Out, huruf Grading diisi otomatis). Sertifikat tanpa gambar latar unggahan memakai desain contoh POSI (`assets/certificate/latar-sertifikat.jpg`: judul, logo, stempel & maskot) dengan nomor `{urut}/POSI/OSN/{bulan romawi}/{tahun}` (urut lintas semua kelas), nama huruf sambung, isi dengan **teks tebal** dan penanda `{mulai}`/`{selesai}`, kota & tanggal, nama penanda tangan.

  - **Petunjuk 50:50** (3x per permainan, `GAME_HINTS` di `src/lib/game-rules.ts`): membuang pengecoh sampai tersisa 2 pilihan (jawaban benar + 1 pengecoh acak). Jatah & opsi yang dibuang ditentukan server (`takeHintAction`, dicatat di sesi bermain) — tidak mengurangi skor.
  - **Pembahasan langsung** setelah menjawab (benar, salah, atau waktu habis): saat salah tampil juga *Jawaban benar*. Kolom `game_questions.explanation` (LaTeX didukung) — diisi manual di form soal, otomatis dari *Generate soal AI*, atau tombol **Lengkapi pembahasan AI** (soal lama tanpa pembahasan, 15 soal per klik). Pembahasan baru dikirim ke browser setelah soal dijawab.
  - **Maskot kucing kuning** (`src/components/game-cat.tsx`, SVG + animasi CSS `cat-*` di `globals.css`) dengan 7 ekspresi sesuai jawaban beruntun: netral (awal) · senyum (1 benar) · tertawa (3) · girang melompat (5+) · sedih (1 salah) · berkaca-kaca (3) · menangis deras (5+), plus balon ucapan.
- Keluaran AI dirapikan dengan `repairLatex` (`src/lib/latex.ts`): escape JSON yang merusak rumus (`\t`ext → tab, `\f`rac → form feed, `^circ` tanpa backslash) diperbaiki sebelum divalidasi.

## Deploy produksi (VPS aaPanel)

- URL: **https://pelatihan.posi.my.id** — folder `/www/wwwroot/pelatihan.posi.my.id`, proses pm2 **`pelatihan-posi`** (Node 20, `127.0.0.1:3030`), database MariaDB **`pelatihan_posi`** (user khusus `pelatihan_posi`, hanya akses DB ini). `.env` produksi ada di folder tersebut (izin 600).
- Nginx: proxy di `/www/server/panel/vhost/nginx/proxy/pelatihan.posi.my.id/`; SSL Let's Encrypt diatur & diperpanjang oleh aaPanel. Cadangan konfigurasi awal: `/root/pelatihan-deploy-backup/`.
- Build dilakukan di laptop (`output: "standalone"`, engine Prisma `debian-openssl-3.0.x`), lalu diunggah — RAM VPS dipakai bersama banyak aplikasi lain.
- Update aplikasi:
  1. `npm run build` di laptop, lalu salin `.next/standalone/*` (tanpa `.env`) + `.next/static` → `.next/static` + `public`.
  2. Unggah & timpa di folder VPS (jangan timpa `.env`, `ecosystem.config.cjs`, dan `storage/`).
  3. Bila ada migrasi baru: jalankan SQL dari `prisma/migrations/<baru>/migration.sql` ke DB `pelatihan_posi`.
  4. `pm2 restart pelatihan-posi`.
- **wa-gateway (Chat WA)** — di laptop jalankan `npm run dev:wa` di terminal kedua (selain `npm run dev`). Di VPS: proses pm2 kedua, dipasang sekali:
  1. Salin folder `wa-gateway/` (tanpa `auth/`, `.env`, `node_modules`) ke **`/opt/pelatihan-wa-gateway`** (di luar folder web, agar sesi WhatsApp tidak mungkin terbuka lewat web), lalu `npm ci --omit=dev` di sana.
  2. Buat `wa-gateway/.env` dari `.env.example` (izin 600): `WA_GATEWAY_SECRET` acak ≥ 24 karakter, `WA_APP_HOOK_URL=http://127.0.0.1:3030/api/wa/hook`. Pastikan port `3031` belum dipakai aplikasi lain.
  3. Tambahkan ke `.env` aplikasi: `WA_GATEWAY_URL=http://127.0.0.1:3031` dan `WA_GATEWAY_SECRET` yang sama, lalu `pm2 restart pelatihan-posi`.
  4. `cd /opt/pelatihan-wa-gateway && pm2 start ecosystem.config.cjs && pm2 save` (selalu 1 instance). Tidak perlu mengubah nginx — gateway hanya diakses dari dalam server.
  5. Folder `/opt/pelatihan-wa-gateway/auth/` berisi sesi login WhatsApp setiap admin: jangan dibagikan; ikut dicadangkan bersama `storage/`. Menghapus foldernya = semua admin harus scan QR ulang.
